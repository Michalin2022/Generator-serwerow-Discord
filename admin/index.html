Konfiguracja każdej aplikacji bota (Discord)

W discord.com/developers/applications, dla każdego bota:
  1. Bot → włącz Public Bot (bez tego nikt poza Tobą nie doda bota).
  2. OAuth2 → Redirects → dodaj dokładnie ten adres i zapisz:
  1. Opcja „Requires OAuth2 Code Grant” ma być wyłączona.
Przycisk „Test” przy bocie pokazuje, czy bot jest publiczny.
